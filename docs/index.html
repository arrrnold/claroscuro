Claroscuro

Un fondo de pantalla para macOS que cambia solo con el modo claro y el modo oscuro.

Todo ocurre en tu navegador. Tus imágenes no se suben a ningún lado.

Descargar claroscuro.heic

Cómo usarlo

  1. Descarga el archivo .heic y guárdalo en una carpeta fija (por ejemplo, Imágenes).
  2. Abre Ajustes del Sistema → Fondo de pantalla y pulsa «Añadir foto» (o arrastra el archivo).
  3. Deja la opción en «Automático». ¡Listo! Cambia de modo y verás cómo cambia el fondo.

También puedes hacer clic derecho en el archivo en Finder → Definir imagen de escritorio.

Tu navegador no puede crear el archivo
